本轮发现并修复了清除首页图标时错误使用资源 0 的崩溃，以及文件被外部删除后 DocumentsProvider 仍返回旧记录的问题。上述结果均来自修复后的正式 APK。独立签名 SHA-256 为 d9838dde0da8aa676cc6714de70627095cd2ea163033a26a364f11571bc4a0c0；APK 校验见 SHA256SUMS.txt。APK 约 16.7 MB，不包含用户播客；上游自带 6 KB no_streaming 提示音保留。

文案口径：相同脚本中原 Library/Transcript 两文件的弹窗构造点由 3 降为 0；新增 History 中保留 1 处主动删除确认。历史 zip_* 42 条资源保留以兼容源码，新页面增加 paper_*；没有把这组资源变化包装成全 App 文案减少四成。用户导入的简介、正文和文字稿不计入界面冗余文案。

模拟器不能证明实体蓝牙耳机、不同手机厂商后台策略或真实触感。你只需直接体验成品；这些真实设备表现单独保留为未验证，不要求执行测试清单。原包 com.homeo.sixmin.kitchen 与新版可并存，新版首次使用需重新导入。私钥保存在仓库外，备份方法见 README；源码与附件不包含私钥或口令。
